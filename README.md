# Derek Mercedes — Portfolio

A CRT-styled portfolio site built with Vue 3 and Vite. The interface emulates an old-school monitor while presenting professional experience, projects, and contact information.

## Live Site

[https://www.derekmercedes.com](https://www.derekmercedes.com)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Technologies

- Vue 3
- Vue Router
- Vite
- TypeScript
